# RGNLabs: ESP32-S3 Voice Assistant Boilerplate

A minimal, clean-slate boilerplate for building customized voice control hardware using an ESP32-S3 microcontroller. This repository provides the essential configuration structure to get your voice assistant up and running with ESPHome and Home Assistant, without the bloat of heavy framework abstractions.

## Overview
This boilerplate is designed to be a starting point for DIY electronics enthusiasts and smart home tinkerers. It provides a modular approach to configuring I2S audio, microphones, and Voice Assistant logic on the powerful ESP32-S3 platform.

## Getting Started

### 1. Prerequisites
- **ESPHome:** Installed and set up.
- **Home Assistant:** Configured with the Voice Assistant integration.
- **Hardware:** An ESP32-S3 N16R8 development board and compatible I2S microphone/amplifier (e.g., INMP441, PCM5102).
